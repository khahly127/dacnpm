# Dacnpm

Dự án ứng dụng web cho phép người dùng gọi món ăn qua QR code.

## Cấu trúc dự án

- `backend/`: API server bằng Node.js + Express + TypeScript + Supabase
- `frontend/`: giao diện người dùng (nếu có trong tương lai hoặc đang phát triển)

## Backend

Xem hướng dẫn chi tiết tại [backend/README.md](./backend/README.md).

## Khởi chạy backend

```bash
cd backend
npm install
npm run dev
```

Mặc định API sẽ chạy tại `http://localhost:3000`.
